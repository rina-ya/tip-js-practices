## 8. Расширение (вариант А)

Реализован поиск задач по части названия в модуле `src/task-extra.js`:

```js
export function searchTasks(tasks, query) {
  if (typeof query !== "string") {
    return [];
  }
  const normalized = query.trim().toLowerCase();
  if (normalized === "") {
    return [...tasks];
  }
  return tasks.filter((task) =>
    task.title.toLowerCase().includes(normalized)
  );
}
```

Контракт:

- `tasks` — корректный массив модели.
- `query` — строка.
- Пробелы по краям удаляются, поиск без учёта регистра, порядок сохраняется.
- Пустой или пробельный запрос возвращает новый массив всех задач.
- Исходные записи не изменяются.

Проверки расширения:

| Проверка | Входные данные | Ожидаемый результат | Фактический результат | Итог |
|---|---|---|---|---|
| Обычный запрос | `searchTasks(demoTasks, "функции")` | `[1]` | `[1]` | Пройдено |
| Разный регистр | `searchTasks(demoTasks, "ФУНКЦИИ")` | `[1]` | `[1]` | Пройдено |
| Краевые пробелы | `searchTasks(demoTasks, "  ФУНК  ")` | `[1]` | `[1]` | Пройдено |
| Нет совпадений | `searchTasks(demoTasks, "несуществующий фрагмент")` | `[]` | `[]` | Пройдено |
| Пустой запрос | `searchTasks(demoTasks, "")`, `"   "` | все задачи | все задачи | Пройдено |
| Пустой список | `searchTasks([], "функции")` | `[]` | `[]` | Пройдено |
| Сохранность данных | снимок `demoTasks` до и после вызова | без изменений | без изменений | Пройдено |
