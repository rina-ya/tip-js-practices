# Практическая работа № 5

**Тема:** Асинхронность, fetch и HTTP API.  
**Автор:** Гиниятова Арина Игоревна, ЭФБО-13-25. **Вариант:** 1.

Реализованы формирование URL, JSON-клиент и предметный модуль задач.
Фильтры передаются серверу через query. Клиент проверяет HTTP-статус,
Content-Type, JSON и схему данных; различает `http`, `network`,
`invalid-response`, `timeout`, `aborted`. Задачи и категории загружаются
параллельно через Promise.all. Учебный сервер взят из заготовки курса.

Из папки `practice-05` (Node.js v24.21.0, npm 11.19.0):

Для запуска двойным щелчком откройте `start.cmd`. Он запускает API и
консольный клиент, выводит таблицу задач и обработанную ошибку 404, затем
оставляет окно открытым. Если порт 5505 занят ПР6, автоматически используется
5515 или 5518; точный адрес API выводится в консоли.

Для ручного запуска:

```powershell
npm.cmd start
```

API: <http://127.0.0.1:5505/api>. Во втором терминале из той же папки:

```powershell
npm.cmd run client
```
