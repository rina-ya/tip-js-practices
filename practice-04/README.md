**Тема:** Формы, валидация и локальное хранение данных.  
**Автор:** Гиниятова Арина Игоревна, ЭФБО-13-25. **Вариант:** 1.

Перенесены собственные данные, сервис, фильтры и отрисовка ПР3. Добавлены
`updateTask`, форма создания и редактирования, проверка полей и хранение
`{ version: 1, tasks }` в localStorage. Сводка считается по всему списку.
При редактировании сохраняются id и completed; исходные данные не изменяются.
Ошибки чтения, JSON, схемы и записи обрабатываются без остановки приложения.
Ключи общего и индивидуального наборов различаются. Сброс удаляет один ключ.

Из папки `practice-04` (Node.js v24.21.0, npm 11.19.0):

Для запуска двойным щелчком откройте `start.cmd`. Он запускает сервер и
открывает основное приложение в браузере. Открытый напрямую HTML автоматически
переходит на HTTP, если сервер работает; иначе показывает инструкцию запуска.
Страница `examples/forms-storage.html` предназначена для экспериментов;
задачи создаются на главной странице приложения.

```powershell
npm.cmd start
```
