# Практическая работа № 6

**Тема:** Подключение браузерного приложения к API.  
**Автор:** Гиниятова Арина Игоревна, ЭФБО-13-25. **Вариант:** 1.

Клиент ПР5 расширен методами POST, PATCH и DELETE, JSON-телами и ответом
204 без разбора JSON. Контроллер управляет созданием, редактированием,
статусом, удалением, фильтрами и сбросом данных. После мутации выполняется
новый GET с текущими фильтрами. localStorage не является источником данных.

Состояния списка: loading, ready, empty, error. Предыдущая загрузка отменяется
через AbortController; номер запроса дополнительно защищает от старого ответа.
Во время мутации кнопки блокируются. Пользовательские строки выводятся через
textContent. Учебный API, HTML, CSS и DOM-адаптер взяты из заготовки курса.

Из папки `practice-06` (Node.js v24.21.0, npm 11.19.0):

Для запуска двойным щелчком откройте `start.cmd`: он проверяет и запускает
API и сайт, затем открывает приложение в обычном браузере. Если на порту
5505 работает API ПР5, выбирается 5516 или 5517. Адрес автоматически
передаётся приложению и сохраняется при переходе к своему варианту и перезагрузке.
Повторный запуск использует уже работающий API ПР6, сохраняя его данные.
Открытый напрямую HTML переходит на HTTP, если сервер работает; иначе показывает инструкцию.

При ручном запуске на стандартных портах сначала остановить API ПР5:

```powershell
npm.cmd start
```

Одновременно запускаются приложение <http://127.0.0.1:5506/> и API
<http://127.0.0.1:5505/api>. Остановка — Ctrl+C.
Вариант: <http://127.0.0.1:5506/?dataset=variant>.

Проверки: `npm.cmd test` и <http://127.0.0.1:5506/checks.html>.
